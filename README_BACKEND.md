# 🔍 DocLens AI — Backend

> FastAPI backend for the AI-powered, ADE-compatible, schema-driven document extraction and intelligence platform.

## Overview

The backend powers all document parsing, schema-driven extraction, AI orchestration, authentication, and job management for the DocLens AI platform. It parses documents (PDF, DOCX, images, spreadsheets, web pages) and extracts structured data using heuristics, OCR, and multiple AI providers — all through a clean REST API.
